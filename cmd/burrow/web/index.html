          NAT mapping types
          How to tell EIM, ADM and APDM apart
        
        
      
      


      

        

          
            

              Type
              Name
              Mapping key
              Meaning
            

          
          
            

              EIM
              Endpoint-Independent Mapping
              Local IP:port
              The same local endpoint keeps one public mapping for every destination.
            

            

              ADM
              Address-Dependent Mapping
              Local IP:port + destination IP
              The mapping is reused across ports of one destination IP; a new destination IP may get a new mapping.
            

            

              APDM
              Address and Port-Dependent Mapping
              Local IP:port + destination IP:port
              Both destination IP and port select the mapping; a new destination port may get a new mapping.
            

          
        

      


      

        
How to identify

        

          

            01 - Compare destination ports
            
If several ports of one destination IP see the same public mapping, the NAT is an EIM/ADM candidate; if the mapping changes with the destination port, it is an APDM candidate.

          

          

            02 - Add a destination IP
            
Repeat the probe against a second public IP. If both destination IPs share the mapping, the NAT is EIM; if the mapping changes with the destination IP, it is ADM.

          

          

            03 - Confirm over several rounds
            
Each round opens a new mapping from a new local port. Consistent results across rounds give a more reliable classification.

          

        

        
Mapping type describes how outbound connections are translated. Inbound filtering is a separate NAT property and needs its own test.

      

      

    


    

      
        
          Reading STUN results
          stun.miwifi.com:3478 and NAT classification
        
        
      
      


      

        

          
            

              Type
              Name
              Typical combination
              Meaning
            

          
          
            

              FC
              Full Cone NAT
              EIM + EIF
              The public mapping is widely reused and inbound filtering is open; UDP hole punching works well.
            

            

              RC
              Restricted Cone NAT
              EIM + ADF
              The public mapping is stable; inbound traffic must come from an IP that was contacted.
            

            

              PRC
              Port Restricted Cone NAT
              EIM + APDF
              The public mapping is stable; inbound traffic must match both a contacted IP and port.
            

            

              SYM
              Symmetric NAT
              APDM + APDF
              The public mapping depends on destination IP and port; hole punching usually needs port prediction or candidate scanning.
            

          
        

      


      

        
What is measured

        

          

            01 - Public mapping
            
A basic Binding request returns the public UDP address: the IP and port of this socket after NAT translation.

          

          

            02 - Mapping behavior
            
EIM, ADM and APDM describe how much the public mapping depends on the destination address and port.

          

          

            03 - Filtering behavior
            
EIF, ADF and APDF describe which source IPs and ports the NAT accepts for inbound traffic.

          

        

        
A full classification needs a STUN server that supports RFC 5780 OTHER-ADDRESS and CHANGE-REQUEST. A basic server still reports the public mapping; the run output states what the server supports.
